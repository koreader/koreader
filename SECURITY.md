# Security Policy

## Supported Versions

Security fixes are provided for the latest monthly release and `master`.
Older releases are supported on a best-effort basis — please verify
suspected vulnerabilities on the latest release (or `master`) before
reporting.

| Version | Supported          |
| ------- | ------------------ |
| Latest monthly release | :white_check_mark: |
| `master` | :white_check_mark: |
| Older releases | Best effort |

## Reporting a Vulnerability

Please do not open a public GitHub issue for suspected security
vulnerabilities.

- If private vulnerability reporting is enabled on this repository,
  please use it (Security tab → Report a vulnerability).
- Otherwise, contact the maintainers privately and ask for a secure
  channel before sharing exploit details, PoCs, or logs.

When reporting privately, please include as much of the following as
you can:

- KOReader version (or commit SHA) and device platform
- Steps to reproduce, PoC, or a minimal redacted reproduction
- Expected impact and likely attack preconditions
- Whether the issue affects default settings or requires specific
  plugins/features to be enabled

Please avoid public disclosure until a fix is available and a
coordinated disclosure timeline has been agreed with the maintainers.
